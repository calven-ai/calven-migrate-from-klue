# Repository instructions

calven-migrate-from-klue is a dependency-free Node.js CLI that exports a customer's own Klue cards and battlecards through Klue's official MCP server.

- Keep it dependency-free. Node 20 built-ins only.
- Run `npm test` after every change.
- Never add Klue material (screenshots, logos, copied help text, real card data). Test data stays fictional.
- The disclaimer in `README.md` and `src/cli.mjs` (`DISCLAIMER`) was set by legal review. Change both together, and only with that review.
- Use Klue's name only to say what the tool works with. No claims about Klue beyond what its published terms say.
- Write without em dashes or en dashes.
- `docs/assets/hero-{light,dark}.svg` are generated by `python3 scripts/build-hero.py ../calven-ai-workspace/brand/library` from the brand tokens and the Calven wordmark. Re-run it rather than editing the SVGs. Never add a Klue logo or Klue colours.
